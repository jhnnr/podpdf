# PodPdf REST API Documentation

PodPdf is a privacy-first, stateless PDF processing engine written in pure Rust. All PDF manipulation tools are exposed through HTTP REST endpoints under `/api/v1/pdf/*`.

---

## 🔒 Authentication (API Key Only)

The **only** way to authenticate programmatic requests to the PodPdf API is using an **API Key**.

There are no public login endpoints or API key creation endpoints in the API. API keys must be generated by an authenticated administrator through the PodPdf Web UI.

### How to Generate an API Key

1. Open the PodPdf Web UI in your browser (e.g., `http://localhost:8080`).
2. Sign in with your administrator credentials (default: `admin` / `admin`).
3. Click **Settings** in the top navigation bar.
4. Navigate to the **API Keys** tab.
5. Enter a key label (e.g., `CI Pipeline`, `Python Automation`, `CLI Tool`) and click **Generate**.
6. Copy the generated key (`podpdf_...`).

### Supplying the API Key

Every API request must include the API key in the `X-API-Key` HTTP header:

```http
X-API-Key: podpdf_0123456789abcdef0123456789abcdef
```

Alternatively, you can supply it as a Bearer token:

```http
Authorization: Bearer podpdf_0123456789abcdef0123456789abcdef
```

If the API key is missing or invalid, the server responds with `401 Unauthorized`:

```json
{
  "error": "Unauthorized: An API key (X-API-Key: podpdf_...) is required to use this endpoint. Generate an API key in the PodPdf Web UI Settings.",
  "code": "API_KEY_REQUIRED"
}
```

## 🌐 Base URL & Conventions

- **Base URL:** `http://localhost:8080/api/v1`
- **Health Check:** `GET /health` or `GET /api/v1/health`
- **System Information:** `GET /api/v1/system/info`
- **File Transfers:** All operations use standard `multipart/form-data`.
- **Response Types:**
  - PDF operations return `application/pdf` with `Content-Disposition: attachment; filename="..."`.
  - Batch / Multi-file operations (Split, Extract Images) return `application/zip`.
  - Analysis and inspection endpoints (Metadata Read, Compare, PDF to Text) return `application/json`.
- **Error Schema:**
  ```json
  {
    "error": "Error description",
    "code": "ERROR_CODE"
  }
  ```

## 🛠️ PDF Manipulation Endpoints (`/api/v1/pdf/*`)

All endpoints below require `-H "X-API-Key: <your_api_key>"`.

### 1. Merge PDFs (`POST /api/v1/pdf/merge`)
Combines multiple PDF documents in the order provided into a single file.
- **Multipart Fields:**
  - `files`: One or more PDF files (repeated field).
- **Response:** Merged `application/pdf`.

### 2. Split PDF (`POST /api/v1/pdf/split`)
Splits a PDF into single pages or custom ranges.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `ranges` *(optional)*: Page range specification (e.g. `"1-3, 4, 5-8"`). Omit to split all pages.
- **Response:** `application/zip` containing split files (or `application/pdf` if only one range is requested).

### 3. Rotate Pages (`POST /api/v1/pdf/rotate`)
Rotates pages by 90°, 180°, or 270°.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `angle`: Integer multiple of 90 (`90`, `180`, `270`).
  - `pages` *(optional)*: Comma-separated 1-based page numbers (e.g. `"1, 3, 5"`). Rotates all pages if omitted.
- **Response:** Rotated `application/pdf`.

### 4. Extract Pages (`POST /api/v1/pdf/extract`)
Extracts selected pages into a new PDF document.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `pages`: Comma-separated 1-based page numbers (e.g. `"1, 3, 4"`).
- **Response:** Extracted `application/pdf`.

### 5. Remove Pages (`POST /api/v1/pdf/remove`)
Deletes specified pages from the document with object pruning.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `pages`: Comma-separated page numbers to delete (e.g. `"2, 4"`).
- **Response:** Cleaned `application/pdf`.

### 6. Reorder Pages (`POST /api/v1/pdf/reorder`)
Rearranges document pages into any custom sequence.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `order`: Full sequence of 1-based page indices (e.g. `"3, 1, 2"`).
- **Response:** Reordered `application/pdf`.

### 7. Reverse Page Sequence (`POST /api/v1/pdf/reverse`)
Inverts page order from last to first.
- **Multipart Fields:**
  - `file`: Source PDF file.
- **Response:** Inverted `application/pdf`.

### 8. Crop Margins (`POST /api/v1/pdf/crop`)
Trims page margins by specified points.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `top`, `bottom`, `left`, `right`: Offset values in points.
- **Response:** Cropped `application/pdf`.

### 9. Scale / Resize Page Dimensions (`POST /api/v1/pdf/scale`)
Resizes pages to standard dimensions (`A4`, `Letter`, `A3`, `Legal`).
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `size`: Dimension name (`"A4"`, `"Letter"`, `"A3"`, `"Legal"`).
- **Response:** Resized `application/pdf`.

### 10. Watermark (`POST /api/v1/pdf/watermark`)
Stamps diagonal text watermarks onto document pages.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `text`: Watermark text (default `"CONFIDENTIAL"`).
  - `font_size` *(optional)*: Float (default `48.0`).
  - `angle` *(optional)*: Float degrees (default `45.0`).
  - `pages` *(optional)*: Comma-separated page list.
- **Response:** Watermarked `application/pdf`.

### 11. Page Numbers (`POST /api/v1/pdf/page-numbers`)
Inserts page numbering headers or footers.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `position`: `"bottom-center"`, `"bottom-right"`, `"top-right"`, `"top-center"`.
  - `format`: Format template string (default `"Page {n} of {total}"`).
- **Response:** Numbered `application/pdf`.

### 12. Images to PDF (`POST /api/v1/pdf/images-to-pdf`)
Converts PNG, JPEG, WebP, and BMP images into a PDF document.
- **Multipart Fields:**
  - `files`: One or more image files.
- **Response:** Created `application/pdf`.

### 13. Text to PDF (`POST /api/v1/pdf/text-to-pdf`)
Converts plain text into a paginated PDF document.
- **Multipart Fields:**
  - `text` or `file`: Text content or uploaded `.txt` file.
- **Response:** Generated `application/pdf`.

### 14. PDF to Text (`POST /api/v1/pdf/pdf-to-text`)
Extracts raw text strings from all document pages.
- **Multipart Fields:**
  - `file`: Source PDF file.
- **Response (JSON):**
  ```json
  {
    "text": "--- Page 1 ---\nDocument contents...\n"
  }
  ```

### 15. Extract Images (`POST /api/v1/pdf/extract-images`)
Extracts embedded raster images into a downloadable ZIP archive.
- **Multipart Fields:**
  - `file`: Source PDF file.
- **Response:** `application/zip` containing extracted images.

### 16. Password Protect / Encrypt (`POST /api/v1/pdf/encrypt`)
Encrypts the PDF document using AES-128 security handler.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `password`: User password required to view.
  - `owner_password` *(optional)*: Permissions password.
- **Response:** Encrypted `application/pdf`.

### 17. Unlock / Decrypt (`POST /api/v1/pdf/decrypt`)
Removes password protection from encrypted documents.
- **Multipart Fields:**
  - `file`: Encrypted PDF file.
  - `password`: Password to decrypt.
- **Response:** Unlocked `application/pdf`.

### 18. Flatten PDF (`POST /api/v1/pdf/flatten`)
Flattens annotations, form fields, and comments into static page streams.
- **Multipart Fields:**
  - `file`: Source PDF file.
- **Response:** Flattened `application/pdf`.

### 19. Auto-Redact (`POST /api/v1/pdf/redact`)
Redacts sensitive terms in content streams with `[REDACTED]`.
- **Multipart Fields:**
  - `file`: Source PDF file.
  - `terms`: Comma-separated terms to redact.
- **Response:** Redacted `application/pdf`.

### 20. Compress & Optimize (`POST /api/v1/pdf/compress`)
Recompresses streams, prunes dead objects, and writes with cross-reference object streams.
- **Multipart Fields:**
  - `file`: Source PDF file.
- **Response:** Optimized `application/pdf`.

### 21. Metadata Operations
- **Read:** `POST /api/v1/pdf/metadata/read` (returns JSON metadata)
- **Update:** `POST /api/v1/pdf/metadata/update` (form fields: `title`, `author`, `subject`, `keywords`, returns updated PDF)
- **Strip:** `POST /api/v1/pdf/metadata/strip` (returns anonymized PDF)

### 22. Compare PDFs (`POST /api/v1/pdf/compare`)
Compares two documents across metadata, size, page counts, and extracted text.
- **Multipart Fields:**
  - `file1`: First PDF file.
  - `file2`: Second PDF file.
- **Response (JSON):**
  ```json
  {
    "size_doc1_bytes": 102400,
    "size_doc2_bytes": 104800,
    "page_count_doc1": 5,
    "page_count_doc2": 5,
    "metadata_doc1": { ... },
    "metadata_doc2": { ... },
    "text_identical": true,
    "summary": "File size difference: 2400 bytes"
  }
  ```

## 💻 How-To Guides (cURL Recipes)

### 1. Merge Multiple PDFs via CLI
```bash
curl -X POST http://localhost:8080/api/v1/pdf/merge \
  -H "X-API-Key: podpdf_YOUR_KEY_HERE" \
  -F "files=@chapter1.pdf" \
  -F "files=@chapter2.pdf" \
  --output merged_book.pdf
```

### 2. Compress & Optimize a Large PDF
```bash
curl -X POST http://localhost:8080/api/v1/pdf/compress \
  -H "X-API-Key: podpdf_YOUR_KEY_HERE" \
  -F "file=@presentation.pdf" \
  --output presentation_optimized.pdf
```

### 3. Stamp a Diagonal Watermark
```bash
curl -X POST http://localhost:8080/api/v1/pdf/watermark \
  -H "X-API-Key: podpdf_YOUR_KEY_HERE" \
  -F "file=@contract.pdf" \
  -F "text=CONFIDENTIAL" \
  -F "font_size=48" \
  -F "angle=45" \
  --output contract_watermarked.pdf
```

### 4. Convert Multiple Photos to a Single PDF
```bash
curl -X POST http://localhost:8080/api/v1/pdf/images-to-pdf \
  -H "X-API-Key: podpdf_YOUR_KEY_HERE" \
  -F "files=@receipt1.jpg" \
  -F "files=@receipt2.png" \
  --output receipts.pdf
```

### 5. Password Protect (Encrypt) a PDF
```bash
curl -X POST http://localhost:8080/api/v1/pdf/encrypt \
  -H "X-API-Key: podpdf_YOUR_KEY_HERE" \
  -F "file=@statement.pdf" \
  -F "password=MySecurePassword123" \
  --output statement_protected.pdf
```

### 6. Inspect PDF Metadata
```bash
curl -X POST http://localhost:8080/api/v1/pdf/metadata/read \
  -H "X-API-Key: podpdf_YOUR_KEY_HERE" \
  -F "file=@whitepaper.pdf"
```

### 7. Extract Text from PDF Document
```bash
curl -X POST http://localhost:8080/api/v1/pdf/pdf-to-text \
  -H "X-API-Key: podpdf_YOUR_KEY_HERE" \
  -F "file=@contract.pdf"
```

### 8. Automated CI/CD Script Example (Bash)
```bash
#!/usr/bin/env bash
set -e

# API Key generated from PodPdf Web UI Settings
API_KEY="podpdf_YOUR_KEY_HERE"
API_URL="http://localhost:8080/api/v1"

echo "Compressing generated build documentation..."
curl -s -X POST "$API_URL/pdf/compress" \
  -H "X-API-Key: $API_KEY" \
  -F "file=@target/doc.pdf" \
  --output dist/doc_optimized.pdf

echo "Stamping build metadata and page numbers..."
curl -s -X POST "$API_URL/pdf/page-numbers" \
  -H "X-API-Key: $API_KEY" \
  -F "file=@dist/doc_optimized.pdf" \
  -F "format=Release Build #$GITHUB_RUN_NUMBER - Page {n} of {total}" \
  -F "position=bottom-right" \
  --output dist/release.pdf

echo "Done! Final release artifact in dist/release.pdf"
```
